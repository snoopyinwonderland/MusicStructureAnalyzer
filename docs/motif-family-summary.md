# 구조 분석 Motif 가족 목록

2026-09-15. 오른쪽 주요 Motif는 악보 레이어의 `motifSpans`에서 집계한다. 기존 `work.stats.motifs`의 별도 반복·길이 탐색 결과 대신 같은 가족/변형 번호와 구간을 사용한다.

- 가족 번호순으로 총 등장 횟수, 형태 수, 선율 음표 비중을 표시한다.
- 형태별 접이식 목록에는 기준형/변형, 등장 횟수, 모든 등장 마디와 시작·마지막 음을 표시한다.
- 등장 위치 선택은 악보의 같은 occurrence를 선택하고 상세 패널을 연다. 구조 분석이 꺼져 있으면 켠다.
- 각 형태의 첫 occurrence를 대표 악보와 타 작품 검색에 사용한다. 검색은 기존 동일 작품·제목 제외 정책을 유지한다.
- 비중 = 가족 구간이 덮는 고유 attack 수 / 선택된 선율 stream의 전체 attack 수. tie continuation과 rest는 제외하고 가족 내부 겹침은 중복 계산하지 않는다. 가족 사이 겹침으로 비중 합계가 100%를 넘을 수 있다. duration 비중이나 중요도 점수가 아니다.
- 중복 family/start/end occurrence를 한 번만 센다. 후보가 없거나 제한 미리보기에서는 빈 상태를 표시한다.

이 변경은 집계/표시 계약이며 가족 판정과 Phrase 경계를 변경하지 않는다. 회귀 검사는 겹침, 중복 occurrence, tie continuation, 대표 구간 내부 쉼표 보존을 다룬다.
