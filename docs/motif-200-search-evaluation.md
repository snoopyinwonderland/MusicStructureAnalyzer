- 강조 검증은 검색 alignment 좌표가 excerpt MusicXML의 동일 part/staff/voice/measure ordinal/beat/pitch에 해석되는지, 붉은 target ID를 넣은 XML이 Verovio SVG로 렌더되는지 검사한다. 화면 디자인의 육안 품질까지 증명하지는 않는다.
